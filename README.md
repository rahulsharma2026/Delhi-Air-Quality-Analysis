# Delhi Air Quality Analysis (2021-2024)

## Problem Statement
Analyzed Delhi's daily air pollution data to understand seasonal patterns, Diwali impact, and worst pollution days.

## Tools Used
- Python (Pandas)
- Plotly (Interactive Charts)
- Excel
- Jupyter Notebook

## Key Insights
- Winter season has the highest pollution levels
- Diwali period (Oct-Nov) shows clear spike in AQI
- PM2.5 and PM10 are the major pollutants
- Multiple days AQI crossed 400 (Severe)
